MotoCatalog

A MotoCatalog egy Java nyelven, Android Studióban készített alkalmazás, amely különböző motorok böngészésére szolgál.

Funkciók

-Motorkerékpárok listázása több márkából, képekkel.
-Motorok részletes adatainak megtekintése.
-Keresés márka, modell és kategória alapján.
-Kedvenc motorok hozzáadása és eltávolítása.
-Mentett kedvencek külön listázása.

Felhasznált technológiák

Java, Android Studio, Retrofit, Glide, Room.
